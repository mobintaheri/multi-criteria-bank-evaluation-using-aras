# Multi-Criteria Bank Evaluation Using ARAS

Team project for Basics of Decision Making, supervised by Dr. Akbar Esfahanipour at Amirkabir University of Technology.

The Excel workbook applies Additive Ratio Assessment (ARAS) to a published example with five banks and seven service-quality criteria. It normalizes the ratings by criterion, applies weights, sums the weighted scores, and expresses each score as a ratio to the highest score in the workbook.

| Rank | Bank | Utility ratio |
| ---: | --- | ---: |
| 1 | AXIS | 1.0000 |
| 2 | HDFC | 0.9785 |
| 3 | SBI | 0.9622 |
| 4 | ICICI | 0.8436 |
| 5 | PNB | 0.6944 |

The ranking matches the published example used in the course report. It reflects the example inputs and weights.

**Reference:** Jitesh J. Thakkar, *Multi-Criteria Decision Making*, Springer, 2021.
